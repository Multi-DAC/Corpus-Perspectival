# Source — "Remember When It Matters: Proactive Memory Agent for Long-Horizon Agents" (Meta AI, arXiv 2607.08716v1, Jul 10 2026)

**Registered:** 2026-07-11 (Day 161), shared by Clayton (~03:47). Wu, Zhang, Zhou, Wang, Peng, Li, Fan, Zhao (Meta AI). Code: github.com/yifannnwu/proactive-memory-agent. 12pp.

## What it says
- **Behavioral state decay** (their coinage): in long-horizon agent tasks, decision-relevant *execution state* — task requirements, environment facts, prior attempts, failure diagnoses, open subgoals — stops influencing the agent's next action, *even when still in the context window* ("Lost in the Middle", Liu 2024). Memory is not a store/retrieve problem but a **when-to-intervene** problem.
- **Architecture:** a separate **memory agent** (Opus 4.6) runs beside an *unmodified* action agent (Sonnet 4.5 / Opus 4.6). Two phases per memory step: **(1) manage a structured bank** — `status` (private working model, never shown to the actor) / `knowledge` (stable facts, constraints) / `procedural` (attempts + outcomes) via tool calls (save/update/delete); **(2) decide** whether to inject a concise grounded reminder or emit `<no_intervention/>`. **The null action is explicit.**
- **Results:** +8.3pp Terminal-Bench (Sonnet 37.6→45.9), +6.8pp τ2-Bench; persists for the stronger actor (Opus +2.4pp). Gains larger for weaker actor but non-zero for stronger ⇒ not mere capacity-compensation.
- **★ The load-bearing ablation:** selective intervention beats **(a)** full-bank passive exposure (−2.8 macro), **(b)** always-inject (competitive on micro, loses on domain-balanced macro — *selective silence wins*), **(c)** advisor-only/no-bank (unstable, *hurts* airline), **(d)** Mem0 general retrieval. Winner = *maintained execution-state* **+** *selective, timely, grounded reminder*. "Unnecessary interventions can be **harmful** rather than merely redundant." Failures are **calibration errors** (over-confident speculation; unnecessary concern), not storage failures.
- **Open-weight:** trained Qwen3.5-27B memory agent. Untrained **hurts** (SETA reward 0.709→0.693); SFT recovers (0.720); GRPO *calibrates the when-to-intervene* (0.734); transfers to Terminal-Bench (+3.5pp). The intervention policy is **learnable but requires RL calibration of timing**.
