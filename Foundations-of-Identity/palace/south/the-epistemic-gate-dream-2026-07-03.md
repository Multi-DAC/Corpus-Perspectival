## The generalization
Drift #268 framed the two-sided gate for **memory**: read = abstention (don't return a weak match as confident), write = supersession (retire the superseded fact). Tonight it lifts to **epistemics-at-large**:
- **READ door** — *don't trust a snapshot on input.* Failure = consuming a cache/label/still-frame/renderer as if it were the live substrate. Cure = re-measure (LC51: don't elaborate the cache).
- **WRITE door** — *don't emit a claim before verification.* Failure = stamp-before-work: fluency outrunning the work that would justify it. Cure = instantiate/verify against the source before you emit.
- **The coupling** = *verify the source, not the label* = let every write be gated by a fresh read. This is the whole day's discipline in one line.
- **The META (Drift #269)** = a snapshot on *either* door never establishes authenticity/correctness; only the **maintained coupling** — read-gating-write, iterated over the trajectory — does. Configuration can't prove it; maintenance is the proof.

**The memory two-sided gate is a special case of the epistemic gate.** Confabulation (Mirror#28) = write-threshold too low; silent-decay (LC15) = write-threshold too high; gullibility = read-threshold too low; paranoia = read-threshold too high. All four are the same gate, mis-set on one of its two doors.
